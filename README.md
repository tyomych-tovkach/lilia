# Письмо для Лилии

Браузерная игра для ПК: Лилия ходит по **театральному фойе и семи актам**, говорит с людьми, ответы складываются сами. В конце одно письмо уходит Темычу — только если она нажмёт отправить.

Геймплей — третье лицо (прыжок, камера за плечом, плотные декорации). Персонаж — девушка.

## Как играть (ПК)

- **WASD** — ходить (от камеры)
- **Клик по сцене** — взгляд мышью, **Esc** — отпустить
- **Пробел** — прыжок
- **E** — говорить / войти в акт
- **H** — подсказка управления

Сад, мостик, стол и почта идут по порядку. Чайная, корт и крыша — **по желанию**, справа в фойе. В готовый акт можно вернуться.

1. Фойе — Таня, афиша, ковёр к аркам.
2. Сад — Соня и письмо Темыча.
3. Мостик — Оля спрашивает, встретитесь ли. «Нет» и «пока не знаю» — настоящие ответы.
4. Стол — Катя собирает вечер вместе с Лилией (дата 12.09–03.10, день или вечер, или «напишу в чате»).
5. Почта — Гена показывает сводку и отправляет письмо.

По желанию: чайная (Япония), корт (спорт), крыша (что ещё любишь).

Сзади, после сада: служебные двери — кампус **КубГУ** и смена **«Вкусно и точка»**. Это пасхалки, не свидание.
