# Письмо для Лилии

Браузерная 3D-сцена для ПК: Лилия ходит по японскому фойе и семи актам. С ней только **Тайви** — маленький дракон-призрак, который появляется в каждой комнате и собирает ответы разговором. В конце одно письмо уходит Темычу — только если она сама нажмёт отправить.

Геймплей — третье лицо (прыжок, камера за плечом, плотные декорации). Лилия — девушка в юкате.

## Как играть (ПК)

- **WASD** — ходить (от камеры)
- **Клик по сцене** — взгляд мышью, **Esc** — отпустить
- **Пробел** — прыжок
- **E** — говорить с Тайви / войти в акт
- **H** — подсказка управления

Сад, мостик, стол и почта идут по порядку. Чайная, корт и крыша — **по желанию**, справа в фойе.

1. Фойе — Тайви и ковёр к Акту I.
2. Сад — письмо Темыча на каменном фонаре. Тайви не пересказывает.
3. Мостик — «Да», «Нет», «Пока не знаю». «Нет» театрально ломает декорации; собрать сцену может только «Да». «Пока не знаю» — честная пауза, мир цел.
4. Стол — вечер на двоих (дата 12.09–03.10, день или вечер, или «напишу в чате»).
5. Почта — сводка и одно письмо.

По желанию: чайная (Япония), корт (спорт), крыша (что ещё любишь).

Сзади, после сада: служебные двери — кампус **КубГУ** и смена **«Вкусно и точка»**. Это пасхалки, не свидание.
