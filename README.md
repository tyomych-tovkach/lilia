# Письмо для Лилии

Браузерная игра для ПК: Лилия ходит по **фойе и семи актам**, говорит с людьми, ответы складываются сами. В конце одно письмо уходит Темычу.

Это не матч и не анкета. Геймплей — третье лицо в духе Sackboy (прыжок, пружинящая камера, плотные декорации), персонаж — девушка.

## Как играть (ПК)

- **WASD** — ходить (от камеры)
- **Мышь** — крутить взгляд
- **Пробел** — прыжок
- **E** — говорить / войти в акт

Локации открываются по порядку. В готовый акт можно вернуться, перескочить нельзя.

1. Фойе — Таня и афиша актов.
2. Сад — Соня и письмо Темыча.
3. Чайная — Ая, Япония (до двух ответов).
4. Корт — Рита, спорт (до трёх).
5. Крыша — Нина, секрет.
6. Мостик — Оля, Да / Нет (второе Нет роняет занавес).
7. Стол — Катя, формат встречи, дата 12.09–03.10, день или вечер.
8. Почта — Гена отправляет сводку.

Сбоку: **кампус КубГУ** и ресторан **«Вкусно и точка»** — пасхалки, не свидание.
